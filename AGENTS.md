# AGENTS.md

## Purpose

This repo is a public artifact about designing AI-assisted workflows.

It demonstrates how to structure interactions between human, agent, and system.

## Context

This is not a production codebase.

Examples are minimal and illustrative, not complete systems.

## Agent Role

Agents may be used to:

- generate small artifacts (examples, prompts, scripts)
- refine structure and clarity

Agents should NOT:

- introduce unnecessary complexity
- expand scope beyond the example
- add frameworks or abstractions

## Constraints

- prefer deterministic steps over agent execution where possible
- keep outputs small, bounded, and reviewable
- avoid hidden side effects
- optimize for clarity over completeness

## Principle

Show the pattern, not the full system.
